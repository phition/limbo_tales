# 📊 《Project Limbo Tales》 인게임 광고 순환 및 수익화(BM) 기획 보고서 (v4)

---

## 1. 개요 및 기획 철학

본 문서는 다크 판타지 로그라이트 RPG **《Project Limbo Tales》**의 고유한 게임성(용병 영구 사망의 필연성, 긴장감 넘치는 파밍)을 해치지 않으면서, 유저가 자발적이고 적극적으로 광고를 선택하게 만드는 **보상 번들링(Bundled Rewarded Ads) 및 실제 구글 광고(Google AdMob / AdSense) 연동 가이드**를 정의합니다.

> **핵심 설계 원칙 (v4 반영)**
> 1. **로그라이트 정체성 사수**: 용병의 영구 사망과 승계 시스템을 훼손하는 '전멸 부활'은 전면 배제합니다.
> 2. **경제 인플레이션 방지**: 2배 보상은 수량성 파밍 자원에 한정하며, 고유 장비/오파츠의 복제는 배제합니다.
> 3. **💡 1타 2피(Bundle Value) 전략**: 광고 1회 시청 시 본 보상뿐만 아니라 **[심연 촉매 슬롯 개방권(0/2)]**을 번들로 동시 지급하여 유저 체감 만족도를 극대화합니다.
> 4. **묘지 헌화의 영웅 수 비례 EXP(10%~30%)**: 목재 소모를 완전히 없애고 광고 시청 시 **[안장된 영령 수에 따라 5분간 전투 EXP 10%~30% 가호]**를 즉시 부여합니다.
> 5. **성화 점화 소모 룰**: 불씨 쌓기(1~4스택) 및 불을 꺼뜨리지 않고 유지/연장하는 것은 횟수 차감이 없으며, **완전히 꺼진 후 5스택 완전 점화 시에만 1회 차감**됩니다.

## 2. 코어 보상형 광고 5대 순환

### ① 🔥 신성한 성화(Bonfire) 충전
* **기본 지급**: 매일 자정(00:00) **무료 완전 점화권 5회** 지급.
* **차감 룰**: 
  * 1~4스택을 쌓는 불씨 단계는 횟수를 차감하지 않습니다.
  * 불이 타오르는 도중 추가 목재를 넣어 불을 꺼뜨리지 않고 온기를 연장하는 것도 횟수를 차감하지 않습니다.
  * **불이 완전히 꺼진 상태에서 5스택 도달로 '완전 점화'가 이루어질 때만 1회 차감**됩니다.
* **광고 정책**: 점화권 0회 시 **광고 1회 시청 ➔ 완전 점화권 5회 즉시 재충전**.
* **번들 혜택**: **심연 촉매 슬롯 개방권(0/2) 동시 지급!**

### ② 🛒 심연 원정 견고한 짐수레(Supply Wagon) 충전
* **기본 지급**: 기본 무료 횟수 없음 (**0회 시작**).
* **광고 정책**: 처음부터 **광고 1회 시청 ➔ 30칸 대용량 짐수레 3회 인가**. 3회를 모두 소진하면 다시 광고 1회로 3회 재인가.
* **번들 혜택**: **심연 촉매 슬롯 개방권(0/2) 동시 지급!**

### ③ 🪦 성채 묘지 위령비 헌화 (자원 소모 제거 & 영령 수 비례 EXP)
* **비용**: 목재 공물 비용 완전 제거 (광고 시청으로 완전 대체).
* **EXP 가호 공식**: 
  * 안장된 영령 수에 따라 기본 10%에서 영령 1명당 5%씩 증가 (최대 5명 안장 시 **30%**).
  * `EXP 버프 = Math.min(30, 10 + (영령 수 - 1) * 5)%`
  * 지속 시간: **5분간** 전투 획득 경험치 증폭.
* **번들 혜택**: **심연 촉매 슬롯 개방권(0/2) 동시 지급!**

### ④ 🔮 탐험 채비실 심연 촉매(Catalyst) 4종 슬롯 개방
* **UI 시각화 원칙**: 광고 시청 전에도 카드를 가리지 않고 4종 카드와 상세 효과를 **항상 확인 가능**.
* **슬롯 상태**:
  * **광고 시청 전**: 슬롯 상태가 **`0/0개 선택 가능 (🔒 잠김)`**으로 표시되며 장착이 잠김.
  * **광고 시청 후**: 슬롯 상태가 **`0/2개 선택됨 (✨ 개방됨)`**으로 즉시 전환되어 최대 2개 무료 장착 가능.
* **개방 경로**:
  * 채비실에서 직접 `[🎬 광고 보고 0/2 개방]` 버튼 클릭.
  * 또는 묘지 헌화, 성화, 짐수레 등 **어떤 광고든 1회 시청 완료 시 자동 개방!**
* **촉매 4종 라인업**:
  1. 🧭 **차원의 나침반**: 용병 긴급 이송 대기 1턴 단축 & 비밀 차원 포탈 조기 발견 확률 대폭 상승
  2. 📜 **피의 서약서**: 강적 출현율 상승 & 던전 내 골드 전리품 2배
  3. 📯 **차원의 호각**: 전멸 시 배낭 전리품 10~50% 긴급 회수 보존
  4. 🐸 **황금 두꺼비**: 드랍되는 원자재 자원류를 즉시 골드로 자동 환전 입고

### ⑤ 🏰 성채 귀환 결산 '방주 보급 증폭 (수량 자원 2배)'
* **트리거**: 던전 탐험을 마치고 성채로 안전 귀환 시 전리품 결산 창.
* **적용 대상**:
  * ✅ **2배 적용**: 골드, 목재, 석재, 철광, 가죽, 식량, 에테르, 심연 파편 등 **수량성 파밍 재료 전품목**.
  * ❌ **2배 제외 (1개 유지)**: **장비 아이템(무기/방어구/악세서리), 오파츠, 신화 유물, 비전서**.
* **번들 혜택**: **심연 촉매 슬롯 개방권(0/2) 동시 지급!**

## 3. 📱 실제 구글 광고(Google AdMob) 받아와서 연동하는 방법

현재 코드는 개발 및 웹 환경에서도 즉시 테스트할 수 있는 **구글 공식 테스트 광고 단위 및 인터랙티브 리워드 플레이어(`GoogleAdService`)**가 완비되어 있습니다. 실제 상용 광고를 받아오려면 다음 4단계를 진행합니다.

```
[1단계: AdMob 가입 및 앱 등록] ➔ [2단계: 보상형 광고 단위 생성] ➔ [3단계: 앱 ID 및 플러그인 설정] ➔ [4단계: 배포 및 승인]
```

---

### Step 1. 구글 애드몹(Google AdMob) 가입 및 앱 생성
1. **[Google AdMob 공식 웹사이트](https://admob.google.com)**에 접속하여 구글 계정으로 로그인/가입합니다.
2. 좌측 메뉴에서 **[앱] ➔ [앱 추가]**를 클릭합니다.
3. 플랫폼을 선택합니다:
   * **Android** 선택
   * '지원되는 앱 스토어에 등록되어 있습니까?' ➔ 출시 전이면 **[아니요]** 선택 (출시 후 스토어 링크 연동)
4. 앱 이름을 입력합니다: `Project Limbo Tales`
5. 생성이 완료되면 발급되는 **애드몹 앱 ID(App ID)**를 복사해 둡니다.
   * 예시 형식: `ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY` (물결표 `~`가 들어감)

---

### Step 2. '보상형(Rewarded) 광고 단위' 생성
1. 방금 등록한 앱의 페이지에서 **[광고 단위] ➔ [광고 단위 추가]**를 클릭합니다.
2. 광고 형식 목록 중 **[보상형(Rewarded)]**을 선택합니다.
3. 설정 옵션:
   * **광고 단위 이름**: `Limbo_Rewarded_Core` (또는 성화, 짐수레, 묘지 등으로 세분화 가능)
   * **보상 설정**: 리워드 수량 1 (인게임에서 자체 비즈니스 로직으로 보상 부여하므로 기본값 유지)
4. 저장을 완료하면 **광고 단위 ID(Ad Unit ID)**가 발급됩니다.
   * 예시 형식: `ca-app-pub-XXXXXXXXXXXXXXXX/ZZZZZZZZZZ` (슬래시 `/`가 들어감)

> ⚠️ **매우 중요 (계정 정지 주의)**:
> 실제 광고 단위 ID를 코드에 넣은 상태에서 개발자 본인이 디바이스로 광고를 시청하거나 클릭하면 **부정 클릭(Invalid Activity)으로 구글 계정이 영구 정지**될 수 있습니다. 개발/테스트 중에는 반드시 구글 공식 테스트 단위 ID(`ca-app-pub-3940256099942544/5224354917`)나 AdMob 콘솔의 **[테스트 기기 등록]**을 거친 기기에서만 테스트해야 합니다.

---

### Step 3. Capacitor 모바일 프로젝트 연동 (Android / iOS)

본 프로젝트는 Capacitor 기반이므로 구글 애드몹 공식 커뮤니티 플러그인을 설치하여 연동합니다:

#### 1) 플러그인 설치
```bash
npm install @capacitor-community/admob
npx cap sync
```

#### 2) AndroidManifest.xml 설정 (`android/app/src/main/AndroidManifest.xml`)
`<application>` 태그 내부에 Step 1에서 발급받은 **애드몹 앱 ID**를 추가합니다:
```xml
<manifest>
    <application>
        <!-- Google AdMob 앱 ID 메타데이터 -->
        <meta-data
            android:name="com.google.android.gms.ads.APPLICATION_ID"
            android:value="ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY"/>
    </application>
</manifest>
```

#### 3) 환경 변수 파일(`.env`) 및 설정 모듈(`src/config/adConfig.ts`)에 등록 완료
발급받으신 실제 광고 단위 ID가 안전하게 저장되었습니다:
```env
# 🎬 Google AdMob 설정
# 발급받은 실제 보상형(Rewarded) 광고 단위 키 (기본 등록 완료)
VITE_ADMOB_REWARDED_UNIT_ID=ca-app-pub-6764468741905727/1175554637

# 실제 광고 송출 모드 스위치
# - false (기본값): 계정 정지 방지를 위해 안전 테스트 단위(ca-app-pub-3940256099942544/5224354917) 및 안전 모드 사용
# - true: 위의 실제 광고 단위 키로 실제 구글 광고 즉시 송출
VITE_ENABLE_REAL_ADS=false
```

#### 4) 실제 광고 송출을 시작하고 싶을 때 (원터치 전환)
1. `.env` 파일에서 `VITE_ENABLE_REAL_ADS=true`로 변경하거나,
2. 코드 상에서 `setRealAdsEnabled(true)`를 호출하면 별도의 추가 작업 없이 즉시 실제 광고 송출 모드로 전환됩니다.
3. 모바일 네이티브 앱(Capacitor)에서는 `@capacitor-community/admob` 플러그인을 통해 실제 AdMob 비디오가 재생되고, 웹 브라우저나 오프라인 환경에서는 반응형 내장 플레이어로 안전하게 폴백(Fallback) 처리됩니다.

---

### Step 4. 웹 브라우저 / H5 게임 환경 연동 (AdSense for H5 Games)
웹 플랫폼(itch.io, 자체 웹 도메인 등)으로 서비스할 경우:
1. **Google AdSense** 계정에서 **H5 게임 전용 광고(AdSense for H5 Games)** 베타를 신청하거나, 표준 웹 디스플레이/보상형 스크립트를 수급합니다.
2. `index.html`의 `<head>` 태그에 애드센스 퍼블리셔 클라이언트 태그(`ca-pub-XXXXXXXXXXXXXX`)를 주입합니다.
3. 현재 구현되어 있는 `GoogleAdService`가 브라우저 환경에서 자동으로 구글 스크립트를 로드하고, 차단되거나 로딩 중일 때는 내장 인터랙티브 UI로 완벽히 폴백(Fallback)되어 게임 플레이가 멈추지 않습니다.

## 4. 하루 1시간 플레이 기준 광고 시청 횟수 시뮬레이션

### ⏱️ 1시간 세션 예상 행동 패턴
1. **시작 (0분)**: 묘지 헌화 광고 1회 시청 ➔ 5분간 EXP 10%~30% 가호 & **채비실 촉매 개방(0/2)**.
2. **1~3회차 출격 (0~30분)**:
   * 1회차: 개방된 촉매 2개(나침반 + 호각) 장착 후 출격.
   * 짐수레는 첫 광고 시청으로 충전된 3회분으로 여유롭게 3회 연속 파밍.
3. **4회차 출격 전 (35분)**: 짐수레 3회 모두 소진 ➔ 광고 1회 시청으로 다시 3회 충전 & **촉매 0/2 다시 개방**.
   * 촉매 2개(피의 서약서 + 나침반) 장착 후 대박 파밍 런 출격!
4. **4회차 귀환 결산 (50분)**: 귀환 2배 광고 1회 시청 ➔ 파밍 자원 2배 획득 & **촉매 개방 리필**.
5. **성채 정비 (55분)**: 불이 완전히 꺼진 후 성화 점화 5회 소진 시 광고 1회 시청 ➔ 성화 5회 리필.

### 📊 최종 예상 시청 빈도 및 피로도
* **시간당 평균 광고 시청**: **2 ~ 3회** (최대 4회).
* **유저 체감**: "광고를 보면 짐수레 3회, 성화 5회에 촉매 2개까지 보너스로 얹어주니 스트레스 없이 자발적으로 보게 된다."
* **평가**: 게임의 흐름을 끊지 않는 모범적인 하이브리드 보상형 광고 순환 모델 완성.
